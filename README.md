# 🗣️ 麦麦主动发言插件

让麦麦在群聊或私聊里**主动找你聊天**，不再只是被动回复。

支持**定时发言**和**手动触发**，话题由 AI 自动生成，就像有个热心的群友时不时冒个泡～

---

## ✨ 功能亮点

- 💬 **主动发起话题**：麦麦会按你设定的时间间隔，在指定群里或私聊中抛出话题。
- 🎲 **概率控制**：每次检查时可以按概率决定是否发言，避免太吵。
- 🤖 **智能生成**：使用麦麦自己的对话模型（支持多模型自动切换），生成自然、不重复的话题。
- ⏰ **支持长思考**：模型响应慢时也能等待最长 5 分钟，不会超时失败。
- 🔧 **两种触发方式**：定时自动发言 + 手动命令 `/chat`。
- 🎯 **会话配置超简单**：不用记复杂的 ID，直接填“群:123456”或“私:789012”。

---

## 📦 安装方法

1. 将插件文件夹放入麦麦的 `plugins/` 目录下。
2. 重启麦麦（或在 WebUI 中重载插件）。
3. 在 WebUI 的插件配置页面中，填写你想要麦麦发言的群或私聊（见下方配置说明）。
4. 确保你的麦麦已经配置好了 **utils 模型任务**（一般默认都有），并且有可用的对话模型（如 `gpt-oss-20b`、`deepseek-v4-flash` 等）。

> 如果不会配置模型，请参考麦麦主程序的 `config/model_config.toml` 文件，确保 `[model_task_config.utils]` 里的 `model_list` 有至少一个可用的模型名。

## ⚙️ 配置说明（WebUI 中可改）

| 配置项 | 作用 | 例子/默认值 |
|--------|------|-------------|
| `enabled` | 插件总开关 | `true` |
| `interval_minutes` | 每隔几分钟检查一次（定时发言周期） | `5` 分钟 |
| `probability` | 每次检查时发言的概率（0~1） | `0.3`（30% 概率会发言） |
| `model_task` | 使用麦麦哪个模型任务 | `utils`（一般不用改） |
| `timeout_seconds` | 生成话题时最多等多少秒（模型慢时可调大） | `180` 秒（3 分钟） |
| `target_streams` | **要发言的目标会话列表** | 见下方“如何填写” |

### 🎯 如何填写 `target_streams`？

你不需要去查什么 `stream_id`，直接用**群号**或**QQ号**就行！

填写格式（每行一个）：

- **群聊**：`群:123456` 或 `group:123456`  
- **私聊**：`私:789012` 或 `private:789012`

例子：  
想让麦麦在你自己的群（群号 `114514`）和你的私聊（QQ `10086`）里主动发言，就填写：
群:114514
私:10086

> 注意：如果填了多个，麦麦会轮流检查每个会话，按概率发言。

如果这一项留空，则**不会自动发言**，但你仍可以在私聊或群里发送 `/chat` 命令手动触发一次。

## 🚀 使用方法

### 1. 手动触发

在任何私聊或群聊中发送：
/chat

麦麦就会在当前对话中主动说一句话（类似“大家今天晚饭吃啥呀？”）。

### 2. 定时自动发言

按上面的配置填好 `target_streams`，并设置好 `interval_minutes` 和 `probability`，麦麦就会按周期自动发言。

例如：  
- `interval_minutes = 10`，`probability = 0.5`  
  表示每 10 分钟，对每个目标会话有 50% 的概率说一句话。

## ❓ 常见问题

### 麦麦不说话 / 没反应？

- 检查插件是否启用（`enabled = true`）。
- 检查 `target_streams` 是否填写正确（例如填了“群:123456”但群号写错了）。
- 检查麦麦的 **utils 模型**是否可用（可以在麦麦的日志里看有没有“模型余额不足”等错误）。
- 尝试手动发送 `/chat` 命令，如果手动能成功但定时不行，说明配置的 `target_streams` 可能无效。

### 生成的话题太短 / 太奇怪？

- 这是由你使用的模型决定的。可以换一个更聪明的模型（比如 `gpt-oss-20b` 或 `deepseek-v4-flash`）。
- 你也可以修改插件里的 `prompt`（在 `plugin.py` 中搜索“你是一个热心的群友”，改一改试试）。

### 总是提示“模型思考时间太长”？

- 说明你的模型响应太慢了，可以适当增大 `timeout_seconds`，例如调到 `240` 或 `300`。
- 或者换一个更快的模型。

### 支持其他平台（如微信、Discord）吗？

- 理论上支持，只要麦麦接入了该平台。你需要填写对应平台的 `stream_id`（例如微信群的 ID 格式可能不同），目前插件只内置了 QQ 的简写规则。如果你用其他平台，可以直接填写原始 `stream_id`（例如 `wechat_xxx`）。
